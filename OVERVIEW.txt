🔍 QUICK API REFERENCE

GET /tasks
  Returns: All tasks
  Status:  200 OK

GET /tasks/:id
  Returns: Specific task or 404
  Status:  200 OK or 404 Not Found

POST /tasks
  Creates: New task
  Status:  201 Created or 400 Bad Request
  Required: title, description, completed

PUT /tasks/:id
  Updates: Existing task
  Status:  200 OK or 404 Not Found
  Optional: title, description, completed

DELETE /tasks/:id
  Deletes: Task by ID
  Status:  200 OK or 404 Not Found

📝 EXAMPLE USAGE (PowerShell)

# Get all tasks
Invoke-WebRequest http://localhost:3000/tasks -UseBasicParsing

# Create a task
$body = @{title="Buy milk";description="From store";completed=$false}|ConvertTo-Json
Invoke-WebRequest -Uri http://localhost:3000/tasks -Method Post `
  -ContentType "application/json" -Body $body -UseBasicParsing

# Update a task
$body = @{completed=$true}|ConvertTo-Json
Invoke-WebRequest -Uri http://localhost:3000/tasks/1 -Method Put `
  -ContentType "application/json" -Body $body -UseBasicParsing

# Delete a task
Invoke-WebRequest -Uri http://localhost:3000/tasks/1 -Method Delete -UseBasicParsing
