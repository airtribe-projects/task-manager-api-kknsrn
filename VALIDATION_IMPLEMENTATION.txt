🧪 VALIDATION RULES SUMMARY
─────────────────────────────────────────────────────────────────────────────

TITLE FIELD:
├─ POST: Required ✅
├─ PUT: Optional ✅
├─ Rule: Non-empty string (cannot be "" or "   ")
├─ Auto-trim: Whitespace removed automatically
└─ Error: 400 - "Title is required" or "Title cannot be empty"

DESCRIPTION FIELD:
├─ POST: Required ✅
├─ PUT: Optional ✅
├─ Rule: Non-null value
├─ Auto-trim: Whitespace removed automatically
└─ Error: 400 - "Description is required"

COMPLETED FIELD:
├─ POST: Required ✅
├─ PUT: Optional ✅
├─ Rule: Boolean only (true or false, not string or number)
├─ Type-strict: "true" string rejected, true boolean accepted
└─ Error: 400 - "Completed must be a boolean"

TASK ID (for GET/PUT/DELETE):
├─ Required: Yes
├─ Type: Number
└─ Error if missing: 404 - "Task not found"

TEST 1: Empty Title (Should Fail)

  -H "Content-Type: application/json" \
  -d '{"title":"","description":"Test","completed":false}'

TEST 2: String "true" for Completed (Should Fail)
─────────────────────────────────────────────────

  -H "Content-Type: application/json" \
  -d '{"title":"Task","description":"Desc","completed":"true"}'

Response Status: 400 Bad Request
Response Body: {"success":false,"message":"Completed must be a boolean"}

TEST 3: Valid Request (Should Succeed)
─────────────────────────────────────

  -H "Content-Type: application/json" \
  -d '{"title":"Buy Milk","description":"From store","completed":false}'

Response Status: 201 Created
Response Body: {
  "success": true,
  "message": "Task created successfully",
  "data": {"id":10,"title":"Buy Milk","description":"From store","completed":false}
}

TEST 4: Non-Existent Task (Should Fail with 404)
────────────────────────────────────────────────
curl -X GET http://localhost:3000/tasks/99999
